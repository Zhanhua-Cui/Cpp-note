# 04 · 现代语法糖（C++11/14/17）

> 相对轻松的一篇。目标：让代码更简洁、更安全、意图更清晰。

## 1. auto —— 类型推导

让编译器替你写类型，尤其是那些又长又难写的类型：

```cpp
auto i = 42;                              // int
auto d = 3.14;                            // double
auto it = my_map.begin();                 // std::map<std::string, int>::iterator
auto p  = std::make_unique<Foo>();        // std::unique_ptr<Foo>
```

**注意**：`auto` 会**丢弃引用和顶层 const**：

```cpp
const std::string s = "hi";
auto a = s;            // a 是 std::string（const 丢了，还是拷贝）
const auto& b = s;     // 想保留 const 引用要显式写
```

## 2. decltype —— 取表达式的类型

```cpp
int x = 0;
decltype(x) y = 5;            // y 是 int
decltype(x)   z = x;          // z 是 int（注意：decltype 保留引用）
// 主要用于模板/返回类型推导，日常了解即可
```

## 3. nullptr

用 `nullptr` 取代 `NULL` 和 `0`，类型安全：

```cpp
void f(int);
void f(char*);
f(0);         // ❌ 调 f(int)，你本意可能是空指针
f(nullptr);   // ✅ 明确调 f(char*)
```

## 4. 范围 for

遍历容器再也不用写下标或迭代器：

```cpp
std::vector<int> v{1, 2, 3, 4};

for (int x : v)           // 拷贝遍历
    std::cout << x << ' ';

for (int& x : v)          // 引用遍历：想修改元素
    x *= 2;

for (const auto& x : v)   // 只读遍历（最常用）：不拷贝、不能改
    std::cout << x << ' ';
```

## 5. lambda 表达式

**就地定义匿名函数**，和 `<algorithm>` 是天作之合。

```cpp
[捕获列表](参数列表) -> 返回类型 { 函数体 }
```

```cpp
auto add = [](int a, int b) { return a + b; };   // 简单 lambda
int r = add(2, 3);                                // 5

// 捕获：把外面的变量「带进」lambda
int base = 10;
auto plus_base = [base](int x) { return x + base; };   // 按值捕获（拷贝）

int counter = 0;
auto inc = [&counter]() { ++counter; };                 // 按引用捕获（可修改）
inc();
```

**捕获速查**：

| 写法 | 含义 |
|---|---|
| `[x]` | 按值捕获 x（拷贝一份） |
| `[&x]` | 按引用捕获 x |
| `[=]` | 按值捕获所有用到的东西 |
| `[&]` | 按引用捕获所有用到的东西 |
| `[=, &x]` | 默认按值，x 按引用 |

**和算法配合的经典例子**：

```cpp
std::vector<int> v{5, 1, 4, 2, 3};
std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; }); // 降序

auto it = std::find_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; });
```

## 6. enum class —— 强类型枚举

普通 `enum` 会「漏」到外层作用域、还能隐式转 int，容易撞名：

```cpp
enum Color { red, green };     // ❌ red/green 泄漏到全局
enum Traffic { red, stop };    // ❌ 编译错误：red 重名

enum class Color  { red, green, blue };
enum class Traffic{ red, yellow, green };
Color c = Color::red;          // ✅ 必须加作用域，绝不撞名
// int n = c;                  // ❌ 不能隐式转 int（要显式 static_cast<int>(c)）
```

## 7. override / final

```cpp
class Base {
public:
    virtual void draw() const {}
    virtual void move() {}
};
class Derived : public Base {
public:
    void draw() const override {}   // ✅ 明确「我在重写」
    // void draw() override {}      // ❌ 编译错误：签名不一致，帮你抓 bug
    void move() final {}            // 禁止子类再重写 move
};
```

`override` 的价值：**拼错函数名 / 签名不一致时，编译器直接报错**，而不是悄悄定义一个无关的新函数。

## 8. constexpr —— 编译期计算

```cpp
constexpr int square(int x) { return x * x; }
constexpr int N = square(10);   // N = 100，编译期就算好了
```

## 9. 结构化绑定（C++17）

一次性解包 pair / tuple / 结构体：

```cpp
std::map<std::string, int> m{{"a", 1}, {"b", 2}};

for (auto& [key, value] : m) {      // key、value 自动绑定
    std::cout << key << "=" << value << '\n';
}
```
