# 练习题（先自己做，做完再看参考答案）

> 规则：每题自己写完、编译通过、跑出正确结果，再去翻 `参考答案.md`。
> 建议用 `-fsanitize=address,undefined` 编译，顺便练内存检查。

## 一、基础（热身）

**B1. RAII 计时器**
写一个类 `Timer`，构造时记录开始时间（用 `<chrono>`），析构时打印从构造到析构经过的毫秒数。用它测一段代码的执行时间。

要求：
- 不写任何 `new`/`delete`；
- 时间单位用毫秒。

**B2. 拷贝赋值 vs 移动赋值**
给下面的类补全「拷贝构造、拷贝赋值、移动构造、移动赋值、析构」，每个函数里 `std::cout` 打印自己是谁。然后写出触发场景验证：

```cpp
class Widget {
    std::string name_;
    std::vector<int> data_;
public:
    explicit Widget(std::string n) : name_(std::move(n)), data_(1000, 42) {}
};
```

**B3. 智能指针基本使用**
用 `unique_ptr` 和 `shared_ptr` 各管理一个对象，观察 `use_count` 变化，并解释为什么 `unique_ptr` 不能拷贝。

## 二、进阶（核心）

**A1. 自己实现 String（五法则版）**
写一个 `MyString` 类，持有 `char*`，实现：构造、析构、拷贝构造、拷贝赋值、移动构造、移动赋值（都要 `noexcept`）。提供 `size()`、`c_str()`、`append()`。写 `main` 分别触发拷贝和移动，确认内存不泄漏。

**A2. 打破循环引用**
设计一个双向链表节点（有 `next` 和 `prev`），用智能指针实现，确保整个链表析构时所有节点都被释放、不泄漏。写代码验证。

**A3. 容器 + 算法**
给定 `std::vector<int>`，用 STL 算法（不手写循环）完成：
1. 去重并排序；
2. 统计大于 100 的元素个数；
3. 把所有元素扩大 3 倍存到新 vector；
4. 求平均值。

**A4. lambda 捕获**
写一个函数 `make_counter(int start)`，返回一个 lambda，每调用一次返回值 +1（从 start 开始）。说明你应该按值捕获还是按引用捕获？如果捕获引用会有什么问题？

## 三、挑战（综合）

**C1. 自定义 Vector（移动语义 + RAII + 模板）**
实现一个简化版 `MyVector<T>`：
- 动态数组，支持 `push_back`、`size`、`capacity`、`operator[]`；
- 实现拷贝构造/赋值、移动构造/赋值（`noexcept`）、析构；
- 扩容时用移动语义搬移元素（而不是拷贝）；
- 测试：装一个大对象（比如持有 `std::string` 的结构体），打印扩容时是「移动」还是「拷贝」。

**C2. 引用计数智能指针（shared_ptr 简化版）**
不借助标准库智能指针，自己实现一个 `MySharedPtr<T>`：支持引用计数、拷贝、移动、`operator*`、`operator->`、`use_count`、析构时归零释放。可以和标准库行为对照。
