## 建议学习顺序（重要）

1. **01-RAII与拷贝控制** —— 这是全阶段的「根」，先读这篇，配合 `代码/01_raii.cpp`。
2. **02-移动语义与右值引用** —— 最难的一环，配合 `代码/02_copy_move.cpp`，看不懂就多跑几遍。
3. **03-智能指针** —— 建立在 RAII 和移动语义之上，配合 `代码/03_smart_ptr.cpp`。
4. **04-现代语法糖** —— 相对轻松，配合 `代码/04_modern_syntax.cpp`。
5. **05-STL与算法** —— 收口，把前面学的组合起来，配合 `代码/05_stl.cpp`。
6. 最后做 `练习/练习题.md`，做完对照参考答案。

> 不要跳着读：移动语义依赖拷贝控制，智能指针依赖移动语义，顺序乱了会反复回头。

## 怎么编译运行示例代码

要求：编译器支持 C++17（g++ 8+ / clang++ 7+ / 任意新版 MSVC 均可）。

```bash
# 逐个编译运行
g++ -std=c++17 -Wall -Wextra 代码/01_raii.cpp -o /tmp/raii && /tmp/raii
g++ -std=c++17 -Wall -Wextra 代码/02_copy_move.cpp -o /tmp/copymove && /tmp/copymove
g++ -std=c++17 -Wall -Wextra 代码/03_smart_ptr.cpp -o /tmp/smartptr && /tmp/smartptr
g++ -std=c++17 -Wall -Wextra 代码/04_modern_syntax.cpp -o /tmp/modern && /tmp/modern
g++ -std=c++17 -Wall -Wextra 代码/05_stl.cpp -o /tmp/stl && /tmp/stl
```

推荐额外加内存检查（如果你装了 clang）：

```bash
g++ -std=c++17 -fsanitize=address,undefined 代码/03_smart_ptr.cpp -o /tmp/smartptr_asan
/tmp/smartptr_asan
```

## 学习建议

- 每篇笔记里都有 `## 自测` 小节，读完先自测，答不上来就重读对应段落。
- 代码文件里的注释非常密，**先跑、再逐行读注释、再尝试自己改一个地方看输出变化**。
- 别背语法，去理解三个心智模型：
  1. **对象生命周期**（谁构造、谁析构、什么时候）
  2. **资源所有权**（这块内存/文件/锁归谁管）
  3. **值类别**（左值 vs 右值，决定拷贝还是移动）

## 学完这个阶段后，你该具备的能力

- 能解释并写出 RAII、移动语义、智能指针的代码；
- 代码里几乎不再出现裸 `new` / `delete`；
- 能用「容器 + 算法 + lambda」清晰表达意图；
- 能看懂并开始使用 C++11/14/17 的代码库。
