## 怎么开始

**第 0 步：装 CMake**（一次性的）

```bash
brew install cmake          # macOS
cmake --version             # 验证
```

**第 1 步：先看两篇总纲**

1. [`学习计划.md`](./学习计划.md) —— 了解 U0~U5 全貌和 AI 时代学习原则；
2. [`指南/CMake入门.md`](./指南/CMake入门.md) —— 学会用 CMake 构建。

**第 2 步：按学习计划的 U0 开工**，参考资料在 `知识库/`，实战代码写进 `项目/`。

## 编译运行示例代码

**方式一：CMake（推荐，学完入门教程后就用它）**

```bash
cmake -B build          # 配置
cmake --build build     # 编译全部示例
./build/01_raii         # 运行某个
```

**方式二：直接用 g++（没装 CMake 前应急用）**

```bash
g++ -std=c++17 -Wall -Wextra 知识库/代码/01_raii.cpp -o /tmp/raii && /tmp/raii
```

带内存检查：

```bash
g++ -std=c++17 -fsanitize=address,undefined 知识库/代码/03_smart_ptr.cpp -o /tmp/smartptr_asan
/tmp/smartptr_asan
```

## 学习建议

- 每篇笔记末尾有「自测」，读完先自测，答不上就重读；
- 代码注释很密：**先跑、再逐行读注释、再改一个地方看输出变化**；
- 别背语法，去理解三个心智模型：**对象生命周期、资源所有权、值类别**。

## 学完你该具备的能力

- 代码里几乎不出现裸 `new`/`delete`，用 RAII + 智能指针表达所有权；
- 会用 CMake 建工程、写测试、跑 sanitizer、做 benchmark；
- 能说清「拷贝 vs 移动」「数据竞争 vs 死锁」「缓存命中 vs 未命中」的区别；
- 能读懂并质疑 AI 生成的 C++ 代码，而不是只会跑。
