# 项目目录（对应 学习计划.md 的 U0~U5）

这里放你每个单元「实战产出」的代码。每个子目录对应计划里的一个单元，等你做到那个单元再往里填内容。

```
项目/
├── 00-工具链/   ← U0：从零搭 CMake 工程（lib + app 结构）
├── 01-容器库/   ← U1：MyVector / MyString（RAII + 移动语义 + 测试）
├── 02-并发/     ← U2：线程池 ThreadPool（线程/锁/原子/TSan）
├── 03-泛型/     ← U3：泛型算法 + 编译期计算
├── 04-性能/     ← U4：矩阵乘法优化（缓存/SIMD/benchmark）
└── 05-综合/     ← U5：简易推理引擎等综合实战
```

**使用约定**：

- 每个单元开一个自己的 `CMakeLists.txt`，独立可编译；
- 每个单元都要有测试 + sanitizer 验证（见学习计划里的验收标准）；
- 参考资料在根目录的 `知识库/`（笔记、示例代码、练习），随时查。

> 详细目标、知识点、验收标准，见根目录 [`学习计划.md`](../学习计划.md)。
